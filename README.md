# 每日计划（Mac 桌面常驻 App）

一个窗口常驻桌面右上角，打开就知道今天学什么。只有一个主 App，没有 WidgetKit 小组件。全部本地存储，不联网、不登录。

## 怎么运行

需要 macOS 14 及以上、Xcode。仓库里只有源代码，不含打包好的 App，第一次要自己编译一下。

**用 Xcode 跑**：

```bash
git clone https://github.com/Zhangxy76/DailyPlanMac.git
```

双击 `DailyPlan.xcodeproj` → 左上角选 `DailyPlan` → 按 ⌘R。

**直接用**：按下面的“命令行打包”打出 `DailyPlan.app`，拖进“应用程序”文件夹再打开，这样开机启动最稳。
第一次打开如果提示“无法验证开发者”：打开 系统设置 → 隐私与安全性，往下拉，点“仍要打开”。

**命令行打包**：

```bash
xcodebuild -project DailyPlan.xcodeproj -scheme DailyPlan -configuration Release -derivedDataPath build build
```

打包好的 App 在 `build/Build/Products/Release/DailyPlan.app`。

打开后程序坞里有蓝色的 ☑︎ 图标，点它就能把窗口叫出来；菜单栏右上角也有一个 ☑︎ 图标。不想在程序坞里看到它，可以在齿轮 ⚙︎ / ⋯ 菜单里取消“在程序坞显示”，这样它就只在菜单栏，像小组件一样在后台常驻。

## 窗口怎么用

| 操作 | 怎么做 |
|---|---|
| 钉住 / 取消钉住 | 窗口右上角的图钉按钮，或右键菜单栏图标 → 钉住。钉住 = 一直在最前面，切 App、切桌面空间都在；取消 = 普通窗口，点别的 App 它会藏到后面 |
| 桌面模式 | 齿轮 ⚙︎ / ⋯ 菜单或右键菜单栏图标 → 桌面模式。窗口贴在桌面上（在桌面图标上面一层，能点能打字），别的窗口会盖住它 |
| 在程序坞显示 | 齿轮 ⚙︎ / ⋯ 菜单或右键菜单栏图标 → 在程序坞显示。默认打开 |
| 显示 / 隐藏 | 点程序坞图标显示，或者左键点菜单栏图标切换。点窗口的关闭按钮也只是藏起来，不会退出 |
| 开机启动 | 第一次打开时自动开启。齿轮 ⚙︎ / ⋯ 菜单或右键菜单栏图标 → 开机启动，可以开关。也能在“系统设置 → 通用 → 登录项”里看到 |
| 退出 | 窗口里按 ⌘Q；或者书架右上角的齿轮 ⚙︎ / 书里右上角的 ⋯ → 退出每日计划；或者右键菜单栏图标 → 退出 |
| 拖动 / 缩放 | 拖窗口空白处移动，拖边缘缩放。位置会记住 |

## 书架：选一本计划书

打开 App 先看到**书架**，就像背单词 App 选单词书一样。每本书是一张卡片，上面有：

- 书名和状态：在学中 / 待开始 / 已完成 / 已归档
- 天数、已完成几天、开始日期、上次学到哪天、进度百分比

蓝框的那本是上次打开的书。

| 操作 | 怎么做 |
|---|---|
| 进一本书 | 点它的卡片，就会进到这本书的今天页 |
| 换书 | 点左上角的 **< 书架** 退回书架，再点另一本 |
| 加新书 | 点书架上的 **+ 新书**，见下面的“导入新书” |
| 编辑 / 导出 / 归档 / 删除 | 右键卡片，或者进书后点右上角的 ⋯。删除前会先确认；暂时不学的书可以归档，归档的书收在书架底部的“已归档”里，点开还能看 |

### 同时学好几本书

两种方式都有，自己选：

- **书架顶部的“今天要做”**：把所有“在学中”的书今天的内容排在一起，包括学什么、力扣、临时任务。可以直接打勾，算进各自那本书的打卡。点书名进到那本书；书名右边的 🔥 是连续打卡天数。不想要这块的话，在齿轮 ⚙︎ 菜单里取消“书架顶部显示‘今天要做’”
- **在新窗口打开**：右键书卡片，或者在书里点 ⋯，选“在新窗口打开”；也可以点“今天要做”里书名右边的 ⊞。打开后会单独弹出一个窗口，固定显示这本书，左上角写着“单独窗口”
  - 可以开好几个，各自拖到桌面不同的位置
  - 钉住 / 桌面模式对所有窗口一起生效
  - 关掉单独窗口不影响主窗口；开着的单独窗口，下次打开 App 会自动恢复

每本书都单独存档：天数、打勾、备注都是分开的，换书不会互相覆盖。Python 30 天只是第一次打开时放进书架的第一本书。删了它，App 照样能用，也不会再自动加回来。

## 一本书里怎么用

- **今天页**：顶部是 `< 书架`、书名、`Day X / 总天数 · 日期` 和进度条。下面只有两行：**学什么**和**力扣**，前面的方框可以打勾
- **点“学什么”那行的文字**，会弹出备注：要做什么、怎么做、搜索词（带复制按钮）、过关标准，还有“我的备注”可以自己写。原计划里没写的项（比如 Python 计划没有“怎么做”）直接不显示
- **点力扣那行**，会弹出题目信息和搜索词，比如 `LeetCode 1 Two Sum`
- **今天最重要的一件事**：早上写一句，存在这本书当天的记录里
- **计时**：书架顶部和今天页都有，是同一个计时器，和任务不挂钩。点 15 / 25 / 45 / 60 分钟就开始，或者点“自定义”输入分钟数（1–600，会记住上次填的）。可以暂停、继续、点 × 结束；到点会响一声并弹通知，可以点“再来一次”
- 两行都打勾，这天就算完成，进度条加一
- 昨天没完成的话，会提示“要补吗？”。点“补”打开昨天的内容，点“跳过”就不再提示
- **总览**：点右上角的“总览”，可以看所有天，每行是 Day X、日期、学什么、✓ / ○。点任意一天能看那天的内容并打勾；用左上角的 `< 今天` / `< 总览` 返回

## 今天临时加的任务（可以重复）

- 点今天页顶部“已完成 X / N 天”那一行最右边的 **⊕**，填任务名和时长，比如 `口语练习` + `半小时`。直接在名字里写 `口语练习 半小时` 也行，会自动把“半小时”拆成时长。任务会显示在学什么和力扣下面
- 在总览里点开某一天时，⊕ 会把任务加到那一天
- **频率**：默认“仅今天一次”，也可以选：
  - 每天都有
  - 每周几天（点选周一到周日）
  - 每隔几天（2–30 天）
  - 工作日
  - 周末
- **结束日期**：选了重复之后可以“设结束日期”，不设就一直到这本书的最后一天
- 加好的任务和学什么、力扣一样能打勾。点任务名可以修改；右边的 ⋯ 里也能修改、删除。重复任务的名字后面有 ↻ 图标，鼠标停上去能看到频率
- **改 / 删重复任务**时会先问一句：“只改今天这一次，还是以后都改？”
  - 只改 / 只删今天：只影响今天这一行，以后照旧
  - 以后都改 / 都删：从今天起换成新的样子，或者从今天起不再出现；以前的日子不受影响
- 这些任务**不会改原计划**，也**不影响打卡**，打卡只看学什么和力扣。临时任务按日期存着：在总览里点开以前的某一天，能看到那天加过的任务
- 每本书的任务分开存，换书不串

## 打卡和连续天数

- **打卡**：当天“学什么”和力扣都打勾，就算打卡成功，日历上那天会点亮。当天 23:59 之前打勾都算当天
- **连续打卡**：按自然日算，中间断一天就归零重新算；**累计打卡**不会归零
- **补打卡**：昨天没完成，今天打开会提示“昨天没完成，要补吗？”，点“补”就能补打昨天的卡。补打的只算进累计天数，不算进连续天数，日历上是橙色
- **提前打勾**：给还没到的一天打勾，不会先打卡；等到那天打开 App，会自动记成当天打卡
- **取消打勾**：撤掉那天的打卡，也撤掉还没做的复习
- **学习时长**：每次打卡按 2.5 小时算。⋯ 菜单里勾上“保底 1.5 小时版”后，之后的打卡按 1.5 小时算
- **在哪里看**：
  - 书架卡片上有“连续打卡 X 天 · 累计 Y 天 · 学习 Z 小时”
  - 今天页的进度条下面有“已连续打卡 X 天”；断了会显示“昨天没打卡，今天重新开始”
  - 总览页顶部是打卡日历：蓝色实心 = 已打卡，橙色 = 补打，空心圆 = 缺卡，灰色 = 还没到。点日历里的任意一天，就能看那天的内容
- 每本书的打卡分开算，换书不会串

## 复习提醒和力扣错题本

- **复习**：每完成一天，会在完成后的第 7 天和第 14 天各排一次复习。比如 11/21 完成 Day 1，11/28 和 12/05 的今天页底部就会出现“今天要复习：Day 1 …”
  - 点那行文字会弹出那天的备注，复习就是重做那天的过关标准
  - 做完点“复习完了”。哪天没复习，这条会一直留着，直到你复习完
- **错题本**：力扣那行右边有“难 / 错了”，点一下这道题就进错题本。3 天后，今天页底部会出现“今天要重做力扣：…”
  - 点错了：同一个位置会变成橙色的“⊗ 在错题本”，再点一下就移出
  - 点“做出来了”，这道题就从错题本移出
  - 点“没做出来”，再排到 3 天后
- **计划里写了“重做”的那天**（比如 Day 30 的“1 + 20 + 704 三道重做”）：不管这几道题在不在错题本里，那天今天页底部都会列出这几道题。题名会从前面的天里自动找出来
- **看错题本**：总览页里点“错题本（N 道）”，能看题号、题名、第一次做的日期、下次重做的日期，也能重做、移出
- **提醒方式**：复习和重做的提醒只出现在今天页底部，不弹窗。想要系统通知，可以在齿轮 ⚙︎ / ⋯ 菜单里打开“复习 / 重做提醒发系统通知”（默认关，每天最多提醒一次）

## 导入新书（比如 AI 计划）

1. 在书架上点 **+ 新书**。还没有现成的计划？窗口顶部有“还没有计划？让 AI 帮你生成”：
   - 点**复制提示词**，整段发给 AI（Claude / ChatGPT 都行），不用改。AI 会一个一个问你：想学什么、多少天、每天多久、什么水平、想做出什么、有什么偏好；问完先总结给你确认，你说“可以”它再生成
   - AI 生成的全文直接粘贴进来就能识别：
     - `书名：…` 会自动填成书名
     - `Day 1 · 2026-12-21（周一）：…` 和下面不带 `- ` 的 `学什么：…` 等标签都认识，外面包着 ``` 也没关系
     - “背景原理搜什么”和“计算机逻辑搜什么”是同一项，两种写法都认
     - 选填的“力扣”“复刻项目”“练习 / 作业”，有就单独显示一栏，没有就不显示
   - 不只是编程，练口语、读书、健身这类计划也能用
   - AI 写了“待确认”的地方会标黄，提醒你去改
   - 点“看一眼”可以先看提示词全文
2. 把计划文字粘贴进去，或者点“导入文件…”选一个 .md / .txt。支持三种写法：
   - 按天写：`## Day 1 · 11/21（六）— 变量 + 内存`，下面跟 `- **学什么**：…`、`- **直接搜什么**：…`、`- **动手做什么**：…`、`- **过关标准**：…` 这样的条目，力扣表格也会自动对上
   - 按日期写：`11/21：学什么……`
   - 一行一条任务：每行算一天
3. 点**生成计划**，会打开检查窗口。拿不准的天会标黄 ⚠︎，并写明原因（比如“没找到过关标准”），App 不会自己编内容
4. 在检查窗口里可以改标题、改备注、改日期、改力扣题、加一天（＋）、删一天（－），拖动左边的列表还能换顺序
   - **改日期**：默认打开“改日期时，后面的天跟着顺延”，比如 Day 1 从 11/21 改到 11/23，后面每天都往后挪 2 天。关掉就只改这一天
   - 为了不让两天撞到同一个日期，日期选择有范围：不能早于前一天；关掉顺延时也不能晚于后一天
   - 保存后，那天的打勾、备注、今天最重要的一件事、临时任务会跟着搬到新日期。打卡和复习是按真实日历记的历史，不跟着搬
5. 点**放进书架**

想改已经放进书架的书：右键卡片 → 编辑这本书…。编辑窗口里有“恢复到导入时的版本”。

## 数据存在哪

`~/Library/Application Support/DailyPlan/`

| 文件 | 内容 |
|---|---|
| `plans.json` | 书架上所有的书（含 `archived` 归档标记，力扣题会拆出 `leetcodeId / leetcodeTitleEN / leetcodeTitleCN`）。每个计划里存着导入时的原文 `rawText`，“恢复到导入时的版本”就是重新解析这份原文 |
| `progress.json` | 按书 id 分开存，和计划内容分开。每本书里有：`days`（每天的打勾 `learn` / `leetcode`、今天最重要的一件事 `mostImportant`、我的备注）、`checkins`（按时打卡）、`makeups`（补打）、`hours` / `totalHours` / `hoursPerDay`（学习时长）、`reviews` / `reviewsDone`（复习安排和完成情况）、`wrongLeetcode`（错题本）、`recurringTasks`（重复任务的规则，只存一条，每天按规则生成）；每天的 `days` 里还有 `extraTasks`（这天临时加的任务）、`recurringDone`（这天打了勾的重复任务）和 `overrides`（“只改今天”的改动） |

想从头再来，就退出 App，删掉这个文件夹，再重新打开。

## 和需求文档的出入

- 原计划里没有“怎么做”，没写的项在备注里直接不显示，没有编内容
- 打开 App 先到书架（按需求第 1、4 节）。窗口常驻时，退回书架之前会一直停在你看的那本书里
- `plans.json` / `progress.json` 存在 `~/Library/Application Support/DailyPlan/`，不放在工程文件夹里：App 运行时不能往自己的安装包里写东西
- 旧版本存的数据（`topThing` 字段、按日期直接存的 `progress.json`）会自动转成新格式，之前的数据不会丢
- 补打卡在 `progress.json` 里单独存成 `makeups`，没有放进 `checkins`。这样才能做到“补打只算累计、不算连续”
- 重复任务“以后都改”：旧规则会在前一天结束，从今天起换一条新规则，这样以前那些天显示的还是原来的样子。所以改过的任务在 `recurringTasks` 里可能有两条
- 书架状态多了一种“已结束”：日期已经过了，但没有全部打完勾。全部打完才算“已完成”

## 测试用（只在 Debug 版里有效）

在 Xcode 的 Scheme → Run → Arguments 里加 `-debugToday 2026-12-20`（假装今天是那天，测打卡、复习很方便）、`-dataDir /tmp/test`（用一个测试数据文件夹，不碰真实数据），就能假装今天是那天，不用改系统日期。加 `-snapshotPage today` 可以跳过书架，直接打开当前这本书。

## 工程结构

```
DailyPlanMac/
├── DailyPlan.xcodeproj
├── DailyPlanApp/
│   ├── DailyPlanApp.swift     # 入口
│   ├── FloatingWindow.swift   # 浮动窗口（钉住 / 桌面模式）、每本书的单独窗口、菜单栏、开机启动
│   ├── PlanModel.swift        # 数据模型、日期工具
│   ├── PlanParser.swift       # 粘贴文字 → 每天的任务
│   ├── ProgressStore.swift    # plans.json / progress.json 读写、今天是 Day 几
│   ├── ShelfView.swift        # 书架、“今天要做”汇总
│   ├── ContentView.swift      # 页面切换、今天页、总览、备注卡片
│   ├── StudyTimer.swift       # 计时（常用时长 + 自定义）
│   ├── CheckinModel.swift     # 打卡 / 复习 / 错题本的数据结构
│   ├── CheckinViews.swift     # 打卡日历、连续天数、今天要复习 / 重做、错题本页
│   ├── TaskModel.swift        # 临时任务、重复任务、频率规则
│   ├── TaskStore.swift        # 加 / 改 / 删任务（只改今天 or 以后都改）
│   ├── TaskViews.swift        # 任务行、“加一个今天的任务”、输入框
│   ├── PlanEditorView.swift   # 导入窗口、编辑窗口
│   └── python-plan.md         # 预置计划原文
└── README.md
```
